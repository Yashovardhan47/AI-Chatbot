NeuroFusion AI — Setup Guide
=============================

NEUROSENSE LONG-TERM MEMORY (v4):
  After starting both servers, open http://localhost:5173/memory
  or choose Memory in the chat sidebar.

  Try separate chats:
    1. "My goal is to become a data scientist."
    2. New conversation: "What is my career goal?"
    3. "I live in Anantapur."
    4. "I now live in Bengaluru."
    5. Memory Studio -> select location -> inspect previous version.

  MongoDB stores memories across sessions and server restarts.
  The Anthropic key is needed for AI answers, not manual memory/recall.
  Use Memory Studio to confirm older, ungrounded memories before recall.
  Private mode skips memory for that message; chat transcripts stay saved.

  Config defaults (optional additions to backend/.env):
    MEMORY_LLM_EXTRACTION=false
    MEMORY_CONTEXT_CHARS=6000
    MEMORY_MAX_RESULTS=8
  Set MEMORY_LLM_EXTRACTION=true for optional structured model extraction.
  It adds a provider request for unsupported natural-language statements.

  Tests (from backend):
    pip install -r requirements-dev.txt
    python -m pytest -q
    python -m evaluation.evaluate_memory

  Frontend checks (from frontend):
    npm test
    npm run build

  Detailed design, research hypotheses and limitations: docs/NEUROSENSE.md

WHAT WAS FIXED THIS ROUND (tested with a real production build — 0 errors):

1. REAL LAG SOURCE FOUND -> postcss.config.js was being silently reparsed as
   an ES module on every single Vite request because package.json didn't
   declare "type": "module". Fixed by adding it — confirmed the warning is
   now completely gone by rebuilding twice.

2. SLOW PAGE SWITCHES -> The entire app was ONE 349KB JavaScript bundle.
   Every navigation had to have already loaded all pages' code up front.
   Fixed with route-based code splitting (React.lazy + Suspense): each
   page is now its own small chunk (2KB-20KB) loaded on demand, with an
   instant spinner shown the few ms it takes. Verified in the build output:
     ChatPage        20.72 kB
     DashboardPage    9.72 kB
     AgentsPage       9.72 kB
     SettingsPage     6.01 kB
     ProjectsPage     9.23 kB
   vs. the old single 349KB bundle for everything.

3. vite.config.js -> added optimizeDeps.include for the core libraries so
   Vite doesn't have to discover/pre-bundle them the first time you hit
   a new route in dev mode (this was part of the "first click is slow" issue).

4. LANDING PAGE REBUILT -> exactly 4 visual sections, zero descriptive
   paragraphs about the project:
     Section 1: Hero + one-line tagline + CTA
     Section 2: Live interactive demo tabs (Chat / Dashboard / Agents /
                Memory) inside a browser-chrome mockup frame
     Section 3: Icon-only process flow (Ask → Agents think → Memory
                recalls → Confident answer)
     Section 4: Closing CTA banner

HOW TO RUN:

Terminal 1 - Backend:
  cd backend
  python -m venv .venv
  .venv\Scripts\activate        (Windows)   or   source .venv/bin/activate (Mac/Linux)
  pip install -r requirements.txt
  uvicorn app.main:app --reload --port 8000

  Paste your Anthropic key into backend/.env:
  ANTHROPIC_API_KEY=sk-ant-your_real_key_here

Terminal 2 - Frontend:
  cd frontend
  npm install
  npm run dev

Terminal 3 - MongoDB:
  mongod

Then open: http://localhost:5173

GOOGLE SIGN-IN (optional):
  1. https://console.cloud.google.com/apis/credentials -> Create OAuth Client ID
  2. Authorized origin: http://localhost:5173
  3. Paste the Client ID into frontend/.env (VITE_GOOGLE_CLIENT_ID) and
     backend/.env (GOOGLE_CLIENT_ID), restart both servers.
  Without this, email/password sign-in still works fully — the Google
  button area just shows a small "not configured" note.

ROUTES:

  /register    -> Sign up (Google + email/password)

  /chat        -> Chat (daily session, auto-continues memory)
