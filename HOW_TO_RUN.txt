NeuroSense AI Workspace v6 — Quick Start
========================================

Full setup: docs/RUN_WORKSPACE.md
Design and research scope: docs/NEUROSENSE.md
Actual checks and remaining limits: docs/VALIDATION.md

Docker Desktop (Windows, macOS or Linux):
  1. Copy root .env.example to .env.
  2. Generate two private values:
       python -c "import secrets; print(secrets.token_hex(32))"
     Put one in SECRET_KEY and the other in MONGO_PASSWORD.
  3. Configure Anthropic, or start the optional local-ai Ollama profile
     as described in docs/RUN_WORKSPACE.md.
  4. Run: docker compose up --build -d
  5. Open: http://localhost:8080

Manual development (Python 3.12, Node 22, running MongoDB):
  Copy backend/.env.example to backend/.env and fill private settings.
  Copy frontend/.env.example to frontend/.env.

  Backend terminal:
    cd backend
    python -m venv .venv
    Activate .venv (Windows: .venv\Scripts\activate;
      Linux/macOS: source .venv/bin/activate)
    pip install -r requirements.txt
    uvicorn app.main:app --reload --port 8000

  Second backend terminal, same environment:
    python -m app.worker

  Frontend terminal:
    cd frontend
    npm ci
    npm run dev
  Open: http://localhost:5173

Daily workflow:
  Chat across sessions, inspect/correct saved facts in Memory, import source
  documents in Knowledge, explicitly connect facts in Graph, and create due
  commitments in Continuity. The worker creates in-app reminders; optional
  SMTP reminders require account opt-in. Save a session to preserve eligible
  user quotations. Private turns never enter later snapshots.

Memory, notes, exact passage retrieval, tasks and the inbox work without an
AI key. Generated answers need a configured Anthropic or local Ollama model.
Semantic retrieval also needs an embedding model and an explicitly built index.
Scanned PDFs need external OCR. Local development can auto-verify sign-up
when SMTP is absent; production requires working email or Google OAuth.

Checks:
  backend: pip install -r requirements-dev.txt; python -m pytest -q
  backend: python -m evaluation.evaluate_memory
  frontend: npm test; npm run build

App routes:
  /                     Public landing page
  /login, /register     Sign in and sign up
  /home                 Authenticated workspace home
  /setup                First-time memory choices
  /security             Server session verification and Google linking
  /tour                 Public interactive tour with example records
  /chat                 Streaming chat with evidence receipts
  /memory               Memory Studio and historical recall
  /knowledge            Documents, notes and passage-based Q&A
  /memory-graph         Explicit fact relationships and semantic indexing
  /continuity           Commitments, saved sessions and reminder inbox
  /projects             Project-scoped work
  /agents               Specialist, debate and plan workflows
  /settings             Preferences, workspace export/erasure and password
  /profile              Profile information
